---
name: dsh-superagent-telegram
description: Переписка с оператором в Telegram-чате, к которому привязан тикет.
---

Исполнители используют `orchestrator_read` для контекста сообщения по мере необходимости: `trigger/<id триггера>` — текст сообщения и его позиция в чате оператора. Сообщение имеет вид `{ id, from, at, text }`: `id` — числовой id сообщения Telegram, `from` — id отправителя. Чтение ничего не создаёт и не отправляет.

Ответы публикуются в чат через сам источник, отдельных инструментов для этого не нужно: источник пишет от имени бота, и ответы приходят в тот же чат. Новые сообщения в подписанном чате приходят исполнителю без дополнительных действий. История чата боту недоступна: контекст — только доставленные исполнителю сообщения тикета.

Не используйте прямые запросы к Bot API, если их нет в инструкциях окружения: токен бота принадлежит источнику и не передаётся исполнителю.

Перед существенной работой над новым запросом человека вызовите `orchestrator_ack` с исходным id триггера и коротким текстом, относящимся к запросу. Подтверждение уходит один раз сообщением в чат.
